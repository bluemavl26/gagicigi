왜 만들었나요

ADHD 성향이 있으면 할 일 앱이 오히려 짐이 되곤 해요.

생각은 쉴 새 없이 떠오르는데, 적어두지 않으면 잊고 적어두면 목록에 묻혀요.
목록이 길어질수록 무엇부터 해야 할지 막막해서 시작을 못 해요.
폴더, 태그, 우선순위를 정하다가 정리하는 일 자체가 또 하나의 할 일이 돼요.
체크한 일은 사라지고 못 한 일만 남아서, 해낸 느낌이 남지 않아요.

가지치기는 이 문제를 "기능을 더하는 것"이 아니라 "고민할 거리를 덜어내는 것" 으로 풀었어요.

이렇게 달라요
보통 할 일 앱	가지치기
끝없이 길어지는 목록	나무 한 그루에 집중. 한 화면에 줄기 하나
폴더 · 태그 · 우선순위 설정	분류 0개. 적고 Enter면 끝
체크하면 사라짐	쳐낸 가지 수가 쌓이고, 끝낸 나무는 숲에 모여요
쌓여도 아무 말 없음	가지가 많아지면 새싹 친구가 울면서 하나만 쳐보자고 해요
ADHD 친화 설계 원칙
동작은 두 번 안에 — 적고 Enter로 가지 뻗기, 가지 누르고 쳐내기. 모든 동작이 탭 두 번 안에 끝나요.
한 번에 하나만 보이게 — 지금 키우는 나무 한 그루만 화면에 있어요. 다른 나무는 위쪽 이름을 눌러 바꿔요.
선택지를 줄여요 — 나무 종류도 하나, 가지 메뉴도 "쳐내기 · 잔가지 · 고치기" 세 개뿐이에요.
넘치기 전에 알려줘요 — 가지가 5개를 넘으면 배너로, 6개부터는 새싹 친구가 직접 알려줘요. 잔가지는 3개까지만 뻗을 수 있어요.
실수해도 괜찮아요 — 쳐낸 뒤 4.5초 안에 되돌리기를 누르면 원래대로 돌아와요.
작은 보상을 크게 — 가위 캐릭터가 나와서 싹둑 자르고, 쳐낼 때마다 숫자가 쌓여요. 해낸 일이 눈에 보이는 모양으로 남아요.
혼내지 않아요 — 문구는 모두 부드럽게. "천천히 해도 괜찮아", "오늘도 한 가지만 쳐내보자".
쓰는 법
심기 — 지금 제일 중요한 일 하나를 적으면 줄기가 자라요.
뻗기 — 떠오르는 생각이나 할 일을 적고 Enter. 줄기에서 가지가 하나씩 뻗어요.
잔가지 — 가지를 눌러 "잔가지"를 고르면 그 아래로 세부 할 일을 3개까지 붙일 수 있어요.
쳐내기 — 끝냈거나 지금 안 할 일은 가지를 눌러 "쳐내기". 가위 캐릭터가 싹둑!
줄기 끝내기 — 줄기 이름을 눌러 끝내면 나무가 숲으로 옮겨져요.
휴대폰에 앱처럼 설치하기
아이폰: 사파리로 주소 열기 → 공유 버튼 → 홈 화면에 추가
안드로이드: 크롬으로 주소 열기 → ⋮ 메뉴 → 앱 설치 또는 홈 화면에 추가

설치하면 주소창 없이 앱처럼 열리고, 인터넷이 없어도 쓸 수 있어요.

내 기록은 어디에 저장되나요
나무와 가지는 내 휴대폰(브라우저) 안에만 저장돼요. 서버로 보내지 않아요.
회원가입도 로그인도 없어요.
휴대폰을 바꿀 땐 숲 화면의 "내 숲 파일로 저장" → 새 기기에서 "파일 불러오기".
브라우저 데이터를 지우면 기록도 함께 지워지니, 가끔 파일로 저장해두세요.

└── screenshots/          README용 화면

앱을 고쳐서 다시 올릴 땐 sw.js 맨 위의 VERSION 숫자를 올려주세요. 이미 설치한 사람에게도 새 버전이 들어가요.

가지치기는 의료용 도구가 아니에요. ADHD 진단이나 치료를 대신하지 않고, 일상의 생각 정리를 조금 가볍게 돕기 위해 만들었어요.
